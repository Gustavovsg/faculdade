**README — Projeto de Calculadora em Python**
<br><br><br>
**Projetos**

* Calculadora Terminal

* Calculadora Tkinter

Ambos permitem realizar as operações soma, subtração, multiplicação e divisão e salvam os resultados em resultado.json.
<br><br><br>
**Descrição dos Projetos**

* Calculadora no Terminal

Simples, roda direto no terminal.

Permite ao usuário digitar dois números e escolher a operação.

Mostra o resultado no terminal.

Salva cada cálculo no arquivo resultado.json.
<br><br>
* Calculadora no Tkinter

Interface gráfica simples usando Tkinter.

Campos de entrada para dois números.

Botões para cada operação: Soma, Subtração, Multiplicação, Divisão.

Exibe o resultado diretamente na janela.

Salva cada cálculo no arquivo resultado.json.
<br><br><br>

**Stacks / Tecnologias Utilizadas**

* Linguagem: Python 3

* Bibliotecas padrão:

* json → para salvar os resultados

* tkinter → interface gráfica (Tkinter já vem com Python)
<br><br><br>
**Como Executar**


* No terminal

Abra o terminal ou prompt de comando.

Navegue até a pasta do projeto.

Execute o script:

*python calculadora_terminal.py*

Digite os números e escolha a operação conforme solicitado.

Resultado será exibido no terminal e registrado em resultado.json.
<br><br>
 * No tkinter

Abra o terminal ou prompt de comando.

Navegue até a pasta do projeto.

Execute o script:

*python calculadora_tkinter.py*

Na janela que abrir:

Digite os números nos campos correspondentes

Clique no botão da operação desejada

Resultado será exibido na janela e registrado em resultado.json.
<br><br><br><br>

**Observações Finais**

Os dois projetos compartilham o mesmo arquivo resultado.json se forem executados na mesma pasta.

JSON não está estruturado como lista completa, mas cada linha é um objeto JSON válido.
