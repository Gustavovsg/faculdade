Este repositório contém três pequenos projetos desenvolvidos em Python para fins de prática e aprendizado. Cada um deles representa um exercício diferente: um sistema simples de lanchonete, uma calculadora de IMC e um jogo de dados.

---

### 1. 🍔 Lanchonete
Um sistema de pedidos simples para uma lanchonete. O programa exibe um cardápio e permite ao usuário selecionar itens, ver cardapio, calcular o total do pedido e finalizar a compra.

**Funcionalidades:**
- Exibe menu de produtos com preços
- Permite escolher produtos e quantidades
- Calcula e exibe o valor total da compra

### 2. 🧮 Calculadora de IMC
Calcula o Índice de Massa Corporal (IMC) com base no peso e altura fornecidos pelo usuário.

**Funcionalidades:**
- Entrada de peso (kg) e altura (m)
- Cálculo do IMC
- Classificação do IMC (Magreza, Normal, Sobrepeso, Obesidade, etc.)

### 3. 🎲 Jogo de Dados
Simula um jogo de dados onde o jogador joga contra o computador. Ganha quem tirar o número mais alto.

**Funcionalidades:**
- Simula jogadas de dados para jogador e computador
- Exibe os resultados de cada jogada
- Declara o vencedor
